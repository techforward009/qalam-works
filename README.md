# qalam-works
The Modern Digital Atelier &amp; Workspace for Text, Language, and Urdu/Arabic Typography.
📜 Qalam Works — Master Project Charter & Execution Blueprint
Mission Statement:
"To build a world-class, modern digital atelier and workspace for text, language, and typography enthusiasts, calligraphers, publishers, and translators—seamlessly bridging classical elegance with cutting-edge web technologies and AI agents."
📌 1. Brand Identity & Visual Design Guidelines
•	Visual Aesthetic:
o	Background: Deep Ink Charcoal / Dark Obsidian (#08090C).
o	Panels & Interface: Frosted Glassmorphism (backdrop-blur with subtle translucent borders).
o	Accent Color: Muted Classical Gold (#C5A059) paired with subtle glowing cyan highlights.
•	Typography Hierarchy:
o	UI & English Navigation: Inter / Plus Jakarta Sans.
o	Urdu Body & Classical Text: Noto Naskh Arabic / Amiri.
o	Calligraphy Sandbox: Jamil Noori Nastaliq, Thuluth, Kufic, and Riqa'a (via dynamic web fonts).
•	Hero Element:
o	An interactive, minimalist, and dynamic 3D Calligraphic Pen Nib / Ink Stroke element that reacts smoothly to cursor movement.

📌 3. Core Feature Roadmap & Utility Suite
A. The Hero Text Sandbox (Interactive Canvas)
•	An active online editor on the landing page where users can paste Urdu, Arabic, Persian, or English text to instantly adjust fonts, letter-spacing, line-heights, and visual alignment.
B. Traffic-Magnet Utility Tools (SEO Engine)
1.	Urdu/Arabic Spacing & Kerning Fixer: Automatically repairs broken line breaks, overlapping letters, and irregular spacing caused by soft-paste formats.
2.	Unicode Normalizer: Standardizes mixed Urdu, Arabic, and Persian character codes (e.g., unifying ك/ک and ي/ی) for seamless searchability and print readiness.
3.	Tashkeel Stripper: Instantly strips diacritics (Zabar, Zer, Pesh, Aerab) from complex Arabic/Urdu scripts with a single click.
4.	Smart Word & Character Counter: Highly accurate letter/word counts tailored specifically for complex Nastaliq ligatures.
5.	Text to Clean PDF Exporter: Generates high-resolution, print-ready PDFs while preserving exact typographical layout and font styling.
C. Services & Portfolio Showcase
•	Highlighting high-end professional services (Book Compositing, Multilingual Translation, and Desktop Publishing) with visual "Before & After" interactive showcase cards.
