# OpenRouter مفت آزمائش — محفوظ طریقہ

یہ صرف مسودہ شاخ `khateeb-sermon-local-validation` پر تجربہ ہے، اصل ویب سائٹ میں تبدیلی نہیں۔

## حفاظتی شرطیں

- صرف دو منتخب ماڈل: `google/gemma-4-31b-it:free` (اردو عبارت) اور `nvidia/nemotron-3-ultra-550b-a55b:free` (علیحدہ جانچ)۔
- ہر درخواست سے **پہلے** OpenRouter کے `GET /api/v1/models` پر دونوں ماڈلز کی موجودگی اور اِن پٹ/آؤٹ پٹ کے اصل نرخ **صفر** ہونے کی تصدیق۔
- کسی بھی فراہم کنندے کا ادا شدہ متبادل **استعمال نہیں ہوگا**۔ درخواستوں کی تعداد صرف **دو** ہے، دوبارہ کوشش نہیں کی جائے گی۔
- رازدارانہ کتابی ذخیرہ یا صارفین کی تحریر نہیں بھیجی جائے گی۔ صرف قرآن کی ایک معروف آیت، نہج البلاغہ کا مختصر اقتباس اور **آزمائشی** اردو مفہوم؛ انہیں مصدقہ ترجمہ تصور نہیں کیا جائے گا۔
- یہ ایک چھوٹا امتحان ہے، مکمل 20 منٹ کی منظورشدہ مجلس نہیں۔

## چیک

```sh
npx vitest run tests/openRouterFreeTrial.test.ts
npx tsc --noEmit
node scripts/probe-openrouter-free-sermon.mjs --dry-run
```

ان میں کوئی حقیقی ماڈل درخواست نہیں۔

حقیقی مفت تجربے کے لیے موجودہ `OPENROUTER_API_KEY` کو محفوظ ماحول میں رکھ کر صرف:

```sh
node scripts/probe-openrouter-free-sermon.mjs --live-free
```

GitHub میں صرف `Run OpenRouter free sample` عنوان والا commit `openrouter-free-sample` کام کو چلاتا ہے۔ کوئی PR ضم کرنا یا پروڈکشن شائع کرنا ضروری نہیں۔

نتائج میں اردو الفاظ، دونوں حوالوں کی موجودگی، اصل فراہم کنندہ کے نام، آزاد جانچ کا فیصلہ اور دو مختصر متنی نمونے درج ہوتے ہیں۔ **مفت ماڈل میں نامکمل یا غلط جواب آئے تو اسے کامیاب مجلس نہیں کہا جائے گا۔**
