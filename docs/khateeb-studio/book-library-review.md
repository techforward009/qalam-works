# نجی کتابی ذخیرہ اور میری مجلس

خطیب اسٹوڈیو کی «میری مجلس» میں اب کتابی تلاش، مکمل عبارت، مخصوص پیراگراف کا انتخاب، اور اصل نسخے کے حوالہ کے ساتھ اقتباس محفوظ کرنے کا راستہ موجود ہے۔ کتابی اقتباس کو مصدقہ حدیث یا خطیب کے اپنے نوٹس کا درجہ خودکار طور پر نہیں دیا جاتا۔

## استعمال

1. خطیب اسٹوڈیو میں «میری مجلس / میرا موضوع» کھولیں اور مسودہ منتخب یا تیار کریں۔
2. «کتابی ذخیرہ — تلاش اور اقتباس» کھولیں۔ ریسرچ اسٹوڈیو کی موجودہ نجی رسائی استعمال ہوتی ہے۔
3. پہلی بار `Khateeb-Foundational-Corpus.zip` درآمد کریں۔ اس مرحلے میں کتابوں کی فائلیں نجی Qalam Research Blob میں محفوظ ہوتی ہیں۔
4. کتاب، زبان، اصل نسخہ، نوعیت یا نمبر سے تلاش کریں۔ مکمل عبارت کھول کر مطلوبہ پیراگراف منتخب کریں اور مجلس میں شامل کریں۔
5. مجلس کا backup، دوبارہ کھولنا، نقل اور پرنٹ منتخب متن اور حوالہ برقرار رکھتے ہیں۔

## علمی شناخت

- فراہم کردہ سات DOCX/EPUB نسخوں سے تیار کردہ 2676 حصوں والا پیکیج قبول ہوتا ہے۔ اصل کتابوں کی فائلیں اس repository یا public assets میں شامل نہیں ہیں۔
- تلاش کی normalization اصل متن کو نہیں بدلتی۔ اعراب، اردو/عربی کاف و یاء اور اردو/عربی ہندسے تلاش کے لیے یکساں ہوتے ہیں۔
- نہج البلاغہ کے 238 اور 240 خطبات والے نسخے اور صحیفہ کے مختلف ضمیمے الگ نمبرنگ رکھتے ہیں۔ محض ایک ہی نمبر ہونے پر متن یا ترجمہ نہیں جوڑا جاتا۔
- انگریزی صحیفہ کے ہفتہ وار عنوانات اپنی اصل نامی شناخت میں محفوظ رہتے ہیں۔
- پیراگراف کے اصل الفاظ، source/record fingerprints، مترجم کی معلوم شناخت، اصل فائل، locator اور منتخب پیراگراف نمبر مسودے کا حصہ ہیں۔ نامعلوم کتابی صفحہ گھڑا نہیں جاتا۔
- موجودہ ترجمہ، شرح اور حواشی کی نسبت کتابی نسخے کے مطابق پڑھی جائے۔ پیکیج کی درآمد پوری کتاب کی نئی علمی تصحیح یا ہر روایت کی سندی توثیق نہیں ہے۔
- غیر مسلسل پیراگراف نقل کرتے وقت `[…]` حذف کی جگہ واضح کرتا ہے۔ تبدیل شدہ نسخے کے اقتباسات الگ شناخت رکھتے ہیں۔

## حفاظت اور خطا

`/api/research/book-library` کی catalog، search، record اور import کارروائیاں موجودہ signed research session سے محفوظ ہیں۔ جوابات `private, no-store` ہیں۔ فائل کی حد 4 MiB ہے، ZIP members اور gzip کا کھلنے والا حجم محدود ہے، ہر record کے متن کا SHA-256 اور پورے manifest کی تعداد جانچی جاتی ہے۔

نجی Blob میں الگ `khateeb-foundational/v1/` prefix استعمال ہوتا ہے۔ اصل corpus gzip کے ساتھ محفوظ ہوتا ہے۔ سات version objects کامیابی سے محفوظ ہونے کے بعد ہی active pointer بدلا جاتا ہے؛ نامکمل درآمد پہلے فعال ذخیرے کو نہیں بدلتی۔ فونٹس یا عمومی Blob کے credentials استعمال نہیں ہوتے۔

مسودے میں صرف منتخب پیراگراف کا snapshot محفوظ ہوتا ہے۔ مقامی storage کی خرابی پر محفوظ ہونے کا غلط پیغام نہیں دکھایا جاتا، اور متن مسودے میں باقی رہتا ہے۔ پرانے backups، جن میں کتابی اقتباس نہیں، بھی قبول ہوتے ہیں۔

## جانچ

- پورے اصل ZIP کی درآمد، 2676 records، اور دعا 28 کا مکمل عربی/اردو record اصل پیکیج سے برابر ہونے کی جانچ۔
- نجی API کی رسائی، غلط انتخاب و فائل، interrupted import، search filters، pagination، source numbering اور اصل متن کی حفاظت۔
- اقتباس کے ساتھ duration/research changes، reload، duplicate selection، version identity، backup/restore، quota failure، copy fallback اور print output۔
- React/API/engine کے متعلقہ 42 tests کامیاب۔ پوری suite کے 3818 tests پہلے کامیاب ہوئے؛ ایک PDF test کا مقامی browser path درست کرکے وہ بھی کامیاب ہوا۔ 59 ماحول/fixture پر منحصر tests skipped تھے۔
- اردو/انگریزی، desktop/mobile کی چار Playwright جانچیں کامیاب: مکمل عبارت، پیراگراف کا انتخاب، reload، backup/restore، clipboard fallback، custom print isolation، PDF اور viewport overflow۔ ان UI tests میں کتابی API کے جوابات controlled fixtures تھے؛ اصل ZIP الگ API/engine جانچ میں استعمال ہوا۔ production Blob کی پہلی درآمد تک اس کا live read/write flow آزمودہ نہیں کہا گیا۔
- Next.js production build کامیاب۔ Document Studio کے پہلے سے موجود font tracing warnings اس تبدیلی کے دائرے سے باہر ہیں۔

## پہلے استعمال کی حیثیت

یہ کوڈ نجی درآمد اور استعمال کا راستہ فراہم کرتا ہے۔ اصل پیکیج کی production Blob میں پہلی درآمد ابھی باقی ہے: موجودہ ریسرچ پاس ورڈ Vercel میں sensitive ہے اور connector اس کی قدر فراہم نہیں کرتا۔ اس لیے خودکار login یا کتابوں کے production ذخیرے میں پہلے سے موجود ہونے کا دعویٰ نہیں کیا گیا۔

## مالک کی رسائی کا راستہ

کتابی پینل اب `/api/research/book-library` استعمال کرتا ہے، تاکہ براؤزر موجودہ `Path=/api/research` والی مالک کی کوکی بھیجے۔ پہلے مختلف راستے کی وجہ سے درست لاگ اِن کے باوجود catalog اور import کو 401 ملتا تھا۔ اصل session کی حدود اور دوسرے محفوظ مواد کی اجازت تبدیل نہیں کی گئی۔ براؤزر کی جانچ اصل login، catalog، import validation، logout اور بغیر رسائی درخواستوں کو جانچتی ہے؛ ذخیرے کے بغیر test server پر catalog کا 503 متوقع ہے۔
