# Death and the Hereafter speaking guide pilot

The single-sermon death-akhirah topic now opens a detailed speaking guide, with a brief-points option. Each of its four angles includes attributed Qur'anic text and translation, a central point, an audience question, and an action. Detailed mode adds explanation, an explicitly hypothetical everyday example, and a transition. Urdu and English are supported.

The material is Qalam Works editorial guidance, not a transcript or a quotation from a scholar. The existing Talib Jauhari records remain available and their summaries are explicitly identified as editorial. Verse references use the existing corpus and translation providers. The guide does not invent hadith or historical incidents.

Copy follows the selected guide mode. Print follows the rendered mode and hides selection controls. Timing suggestions total 20, 30, or 45 minutes; they support expansion by the speaker and do not constitute a timed verbatim script. Repeated selected-topic headings were removed, and generic preparation previews are accurately labelled outlines.

Validation: 325 Khateeb tests passed, including eight pilot tests; TypeScript and production webpack build passed. Local Chromium checked four sections, switching, clipboard content, mobile width, and print visibility. First-load English followed by switching to Urdu produced no page errors. An existing site language hydration mismatch occurs when Urdu is preselected in local storage; that global language-provider issue is outside this pilot.

No hosted branch or deployment is changed by this review commit.
