# خطیب اسٹوڈیو: DeepSeek کے براہِ راست رابطے کا آزمائشی منصوبہ

**موجودہ حیثیت:** صرف مسودہ PR #30 کی محفوظ شاخ۔ اسے شائع نہ کریں، اصل ویب سائٹ کا حصہ نہیں بنایا گیا۔ ابھی کسی ادا شدہ ماڈل کو درخواست نہیں بھیجی گئی۔

## آزمائش میں کون سے ماڈل ہوں گے؟

1. مجلس کا مسودہ: **DeepSeek V4.1 Flash**، سرکاری شناخت: `deepseek-flash`۔
2. ہر جملے، آیت، روایت اور حوالے کی آزاد جانچ: **DeepSeek V4 Pro**، شناخت: `deepseek-v4-pro`۔

منظم جواب کے لیے سرکاری `POST /chat/completions` کے ذریعے `response_format: {"type":"json_object"}` استعمال ہوگا۔ نئی خدمت میں بعض دوسرے فراہم کنندگان کا `json_schema` اختیار موجود نہیں؛ اسے واضح طور پر قابلِ قبول JSON میں بدلا گیا ہے، پھر موجودہ سخت داخلی جانچ کی جائے گی۔

## ادائیگی سے پہلے کی مفت جانچ

    npm ci --ignore-scripts --no-audit --no-fund
    npx vitest run tests/deepSeekTrial.test.ts tests/sermonComposer.test.ts tests/sermonStagedGeneration.test.ts
    npx tsc --noEmit
    node scripts/evaluate-sermon-free-models.mjs --deepseek-check

یہ تمام احکامات ماڈل کو کوئی ادا شدہ درخواست نہیں بھیجتے۔ آزمائش میں اصل احمدگراف قرآنی متن اور شیخ محسن علی نجفی کا اردو ترجمہ رکھا گیا ہے۔ الکافی کی بعض فراہم کردہ اردو عبارتیں **آزمائشی ادارتی ترجمہ** ہیں، مصدقہ اشاعتی متن نہیں۔

## حقیقی آزمائش — صرف مالی اجازت اور ادائیگی کے بعد

- پہلے الگ `DEEPSEEK_API_KEY` محفوظ ماحول میں فراہم کی جائے۔ کلید کبھی گفتگو، کوڈ، لاگ یا تصویر میں نہ دکھائیں۔
- سرکاری `GET /user/balance` سے معلوم ہوگا کہ USD کی قابلِ استعمال رقم کم از کم **$0.35** ہے۔ رقم نہ ہو یا خدمات دستیاب نہ ہوں تو تجربہ ختم ہوجائے گا۔
- مطلوبہ واضح اجازت کے بعد درج ذیل حکم چل سکتا ہے:

    node scripts/evaluate-sermon-free-models.mjs --deepseek-trial --allow-paid-api --staged --only=flash

- مقامی تجرباتی نظام کی تخمینی ریزرو حد **$0.35** اور درخواستوں کی تعداد **24** ہے۔ یہ کمپنی کے اصل بل کی یقینی حد نہیں؛ حقیقی اخراجات ماڈل فراہم کنندہ کے اپنے حساب سے کٹتے ہیں، اور ناکام درخواست کا خرچ بھی مختلف ہوسکتا ہے۔
- حساب میں **Peak** کے زیادہ نرخ استعمال کیے گئے ہیں: Flash کے لیے دس لاکھ اِن پٹ/آؤٹ پٹ ٹوکن پر بالترتیب $0.30/$1.20؛ Pro کے لیے $1.32/$3.96۔ قیمت تبدیلی کے قابل ہے۔
- کتابی حوالوں، پانچ حصوں، متعدد اصل غیر قرآنی متون، اردو رسم الخط، ہر جملے کے ثبوت اور اصل قرآنی عبارت کے ساتھ **18 تا 22 منٹ کی تقریری تخمینی مدت** کی جانچ ہوگی۔ اس کے بغیر کوئی مسودہ تیار یا منظور قرار نہیں دیا جائے گا۔

**خصوصی تنبیہ:** یہاں نہ صارف نے رقم جمع کروائی ہے، نہ کوئی حقیقی DeepSeek API ماڈل آزمائش کی گئی ہے۔ سرکاری ویب سائٹ پر نظر آنے والی کم از کم دو ڈالر جمع کروانے کی شرط اس کوڈ سے تبدیل نہیں ہوگی۔ DeepSeek ماڈل کو اپنے خرچ پر آزمانے کا فیصلہ الگ سے کرنا ہوگا۔
