# Qalam IndoPak Quranic

Phase 1A prototype. Original outlines only.

```bash
python3 sources/build_prototype.py
python3 sources/check_prototype.py
```

Open `specimen/index.html` in a browser. It renders the prototype and Noto Naskh on AhmedGraf Quran lines. PDMS Saleem and Muhammadi load from local files and are not in this directory.

This is not the production Quran reader and it is not served by qalamworks.com.
